# Руководство пользователя: плагин ПТ для AutoCAD

Плагин **ПТ** (пожарная сигнализация / объекты и таблицы) работает в **AutoCAD 2022 / 2023** и помогает:

- ставить объекты на чертёж с подписью и символом;
- вести таблицу оборудования на чертеже;
- строить связи между объектами;
- расставлять извещатели по зоне;
- использовать собственные шаблоны символов и горячие клавиши.

---

## 1. Установка и запуск

### Требования

- AutoCAD 2022 или 2023 (x64)
- Собранный файл плагина: `src\DemoAutoCad\WindowsFormsApp1\bin\Debug-2022\Demo.dll` или `bin\Debug-2023\Demo.dll` (в зависимости от версии AutoCAD)

### Первая загрузка

1. Откройте AutoCAD.
2. В командной строке введите: `NETLOAD`
3. Укажите файл `Demo.dll`.
4. Плагин загружен — данные сохраняются **внутри DWG-файла**.

### Обновление плагина

AutoCAD блокирует DLL, пока плагин загружен:

1. `NETUNLOAD` → выгрузить `Demo.dll`
2. Пересобрать проект (или скопировать новый `Demo.dll`)
3. `NETLOAD` снова

### Как открыть панель

| Способ | Действие |
|--------|----------|
| Команда | `PLACEPT` или `PTPANEL` |
| Контекстное меню | ПКМ по чертежу → **«Поставить объект ПТ»** |

Окно плагина **немодальное** — можно работать и с чертежом, и с панелью.

---

## 2. Быстрый старт (5 шагов)

```
1. PLACEPT          → открыть панель
2. «Новая таблица»  → щёлкнуть точку на чертеже
3. Выбрать тип + форму объекта
4. «Добавить»       → щёлкнуть точку вставки
5. Объект появится на чертеже и в таблице
```

**Важно:** без таблицы объекты не добавляются. Сначала всегда создайте хотя бы одну таблицу.

---

## 3. Что появляется на чертеже

При добавлении объекта создаётся:

| Элемент | Описание |
|---------|----------|
| **Фигура** | Прямоугольник, круг, треугольник, блок и т.д. (слой `PT_DEVICES`) |
| **Подпись внутри** | Текст в центре фигуры, например `BTH-11` (слой `PT_TEXT`) |
| **Идентификатор снизу** | Строка вида `*-BTH-11` под объектом |
| **Колонка в таблице** | Код, номер, наименование, FD, JS05 и др. (слой `PT_TABLE`) |
| **Связь (стрелка)** | Если задан родитель или создана связь (слой `PT_LINKS`) |

Подпись **внутри** фигуры автоматически подгоняется под размер — длинный текст уменьшается и переносится, чтобы не выходить за границы.

### Слои плагина

- `PT_TABLE` — таблицы
- `PT_DEVICES` — символы объектов
- `PT_TEXT` — надписи
- `PT_BUS` — шины
- `PT_LINKS` — связи (стрелки)
- `PT_DETECTOR_ZONE` — зоны извещателей (контур + штриховка)

---

## 4. Вкладка «Размещение»

Основная вкладка для постановки объектов.

### Поля

| Поле | Назначение |
|------|------------|
| **Таблица** | К какой таблице относится объект |
| **Новая таблица…** | Создать таблицу в указанной точке |
| **Тип объекта** | BTH, BTM, BIAL, шкафы и др. (справочник в плагине) |
| **Форма** | Геометрия: прямоугольник, круг, готовый блок… |
| **Размер шрифта** | По умолчанию 3.5 |
| **Номер** | Следующий свободный номер для выбранного кода |
| **Подпись** | Текст на чертеже; по умолчанию `КОД-НОМЕР` |
| **Связать с (род.)** | Новый объект сразу свяжется с выбранным родителем |

### Кнопка «Добавить»

1. Панель временно скрывается (иначе AutoCAD не примет щелчок).
2. В командной строке: *«Щёлкните точку вставки объекта»*.
3. После щелчка объект создаётся, панель снова показывается.

**Esc** отменяет указание точки.

### Preview шаблона

Если выбрана **форма из вкладки «Шаблоны объектов»**, показываются превью, код, описание и имя блока. При совпадении кода тип объекта подставляется автоматически.

---

## 5. Вкладка «Таблицы»

Редактирование данных **без правки ячеек на чертеже вручную** — изменения идут через панель и синхронизируются с таблицей AutoCAD.

### Колонки сетки

- **Подпись** — текст на объекте
- **Код**, **Номер**, **Наименование**
- **FD**, **JS05** — служебные коды (заполняются при создании)
- **Блок** — группа блоков (только чтение)

После изменения подписи в сетке надпись на чертеже пересчитывается с учётом границ фигуры.

---

## 6. Вкладка «Связи»

Управление иерархией и связями между объектами.

### Дерево объектов

- Показывает объекты активной таблицы в виде дерева.
- **Добавить** — поставить дочерний объект (родитель = выделенный в дереве).
- **Удалить** — удалить выбранный объект.
- **▲ / ▼** — порядок в дереве.
- **Перетаскивание** — изменить родителя.

### Блоки (группы)

- **Новый блок** — создать именованную группу.
- Выбрать блок в списке → **«В блок»** — добавить выделенный объект в группу.

### Создание связи «От → К»

1. Поля **От** и **К** — выпадающие списки объектов.
2. Кнопки **«В «От»»** / **«В «К»»** — подставить выделенный в дереве объект.
3. Клик по объекту в дереве автоматически ставит его в поле **«К»**.
4. **«Создать связь»** — стрелка на чертеже от одного объекта к другому.

Циклические связи запрещены.

---

## 7. Вкладка «Шаблоны объектов»

Собственные символы вместо стандартных фигур.

### Способы создания шаблона

| Кнопка | Действие |
|--------|----------|
| **Из выделения** | Выделить объекты на чертеже → плагин создаст блок-шаблон |
| **Из таблицы** | Указать таблицу AutoCAD (как в легенде ПС1/ПС2) |
| **Из CSV/Excel** | Импорт из файла |

### Формат CSV

Колонки (разделитель `;`):

```
Код;Описание;Блок;Имя;ФайлDWG
```

Excel: *Сохранить как → CSV (разделители — точка с запятой)*.

### Импорт блока из DWG

1. **Обзор…** — выбрать DWG.
2. Выбрать имя блока в списке.
3. **Импортировать блок**.

### Использование

После создания шаблон появляется в списке **Форма** на вкладке «Размещение». Справа — превью и описание.

**Удаление:** нельзя удалить шаблон, если он уже используется размещёнными объектами.

---

## 8. Вкладка «Горячие клавиши»

Быстрая постановка объектов с клавиатуры, **без конфликта** с обычными командами AutoCAD.

### Принцип работы (двухшаговый режим)

1. Нажать **клавишу входа** (по умолчанию **F11**).
2. Появится оранжевая полоска: *«ПТ — РЕЖИМ ВЫБОРА»*.
3. Нажать **клавишу привязки** (например `1`, `2`, `C`).
4. Выбираются тип/форма → **сразу начинается построение** (указание точки на чертеже).

**Esc** — выход из режима. Таймаут по умолчанию — 8 секунд.

### Привязки по умолчанию

| Клавиша | Действие |
|---------|----------|
| `1` | Тип: BTH (дымовой извещатель) |
| `2` | Тип: BTM (ручной) |
| `3` | Тип: BIAL (оповещатель «Выход») |
| `C` | Форма: круг |

### Настройка

На вкладке «Горячие клавиши»:

- включить/выключить систему;
- задать клавишу входа и таймаут;
- добавить/изменить привязки (тип объекта или форма);
- **Сохранить**.

Файл настроек:

```
%LocalAppData%\.ptautocad_module\hotkeys.json
```

### Рекомендации

- Работайте в чертеже (фокус на AutoCAD), не в полях панели.
- Не используйте для привязок `Esc`, `Tab`, `Enter`, `Space`.
- Горячие клавиши **не работают**, пока активна команда AutoCAD (линия, копирование и т.д.).

## 9. Вкладка «Расставить извещатели»

Автоматическая расстановка дымовых извещателей (круги BTH) внутри заданной области.

### Параметры

| Параметр | Описание |
|----------|----------|
| **Таблица** | Куда записывать извещатели |
| **Радиус, м** | По умолчанию 6.4 м |
| **Шаг сетки** | ≈ R × √2 (показывается подсказкой) |
| **Направление сетки** | Авто / горизонтальные ряды / вертикальные столбцы |
| **Штриховка** | Паттерн зоны (ANSI31, SOLID и др.) |

### Порядок работы

1. Выбрать таблицу и параметры.
2. **«Расставить извещатели»**.
3. Обвести область **полилинией** (минимум 3 точки, Enter для завершения).
4. Плагин:
   - расставит извещатели с минимальным числом точек;
   - заштрихует зону на слое `PT_DETECTOR_ZONE`;
   - добавит объекты в таблицу.

### Зоны

Список **Зоны** — ранее созданные области. **Удалить зону** — убрать контур, штриховку и связанные извещатели.

---

## 10. Справочник типов и форм

### Типы объектов (фрагмент)

BTH, BTK, BTM, BIAL, BIAS, AE, MR, BZ, UPS, MDU, шкафы ДВ/ПД/ПВ/СКУД и др. — полный список в выпадающем списке **Тип объекта**.

### Стандартные формы

- Прямоугольник (28×10 единиц чертежа)
- Квадрат, треугольник, круг, ромб
- Готовые блоки: BZ, MR, MDU, BTH, BIAL

### Структура таблицы на чертеже (строки)

| Строка | Содержимое |
|--------|------------|
| Узел В | Номер колонки |
| (2–3) | FD, JS05 |
| Код | Код типа (BTH…) |
| Номер | Порядковый номер |
| Наименование | Полное имя типа |
| Блок | Имя группы блоков |

## 11. Сохранение данных

| Что | Где хранится |
|-----|--------------|
| Объекты, таблицы, связи, зоны, шаблоны | В DWG (служебные данные плагина) |
| Настройки горячих клавиш | `%LocalAppData%\.ptautocad_module\hotkeys.json` |

При открытии DWG плагин **восстанавливает** состояние автоматически.  
При закрытии чертежа данные **сохраняются** в файл.

**Совет:** регулярно сохраняйте DWG (`QSAVE`).

---

## 12. Служебные команды (для плагина)

Обычно вызываются автоматически, вручную не нужны:

| Команда | Назначение |
|---------|------------|
| `PTPICKADD` | Указание точки вставки объекта |
| `PTPICKNEWTABLE` | Указание точки таблицы |
| `PTPICKDETECTOR` | Обводка зоны извещателей |
| `PTPICKPRECREATE` | Выделение для шаблона |
| `PTPICKLEGENDTABLE` | Выбор таблицы легенды |

## 13. Типичные проблемы

| Проблема | Решение |
|----------|---------|
| «Сначала создайте таблицу» | Вкладка «Размещение» → **Новая таблица…** |
| Не принимает щелчок при добавлении | Панель скрывается сама; не кликайте по ней во время указания точки |
| Горячая клавиша переключает вкладки | Обновите плагин; в режиме F11 вкладки блокируются |
| Выбор по F11 есть, но нет построения | Нужна активная таблица; после выбора должно появиться приглашение указать точку |
| Не собирается Demo.dll | `NETUNLOAD` в AutoCAD, затем пересборка |
| Таблица на чертеже «битая» | Создайте новую таблицу; старые объекты могут ссылаться на удалённую |
| Подпись обрезана / мелкая | Длинный текст ужимается, чтобы влезть в фигуру; укоротите подпись или увеличьте форму (шаблон) |
| Шаблон не удаляется | Сначала смените форму у объектов, которые его используют |

---

## 14. Рекомендуемый рабочий процесс

```
Подготовка
  └─ Импорт шаблонов (при необходимости)
  └─ Настройка горячих клавиш

Чертёж
  └─ Создать таблицу(ы)
  └─ F11 + клавиша  ИЛИ  панель «Добавить»
  └─ Связи на вкладке «Связи»
  └─ Зоны извещателей (отдельные помещения)
  └─ Правки в «Таблицы»

Завершение
  └─ QSAVE
```
